Document Window

PDF Info shows a table of all fonts in the PDF document.

Font List

The table contains the following columns:
  • Name: the name of the font.
  • Subtype: the type of the font.
  • Subset: whether the font is a subset.
  • Embedded: whether the font is embedded in the document.
  • Installed: whether the font is currently install on your system. Installed fonts can be previewed, see Font Preview.

Opening Files

You can open PDF files by right clicking on a PDF file in the Finder and selecting "PDF Info" from the "Open With" menu.
